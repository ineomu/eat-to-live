# Test 4 · 反查场景 · 反复口腔溃疡不是缺维 C

## 输入

> 我最近经常口腔溃疡，舌头还裂口子，是不是缺维生素？

## 期望触发的入口

🚪 **反查**（症状 → 4 大组织 → 关键营养素）

## 期望输出（关键节点）

### 必须出现的关键判断

- [ ] **症状归属**：口腔黏膜 + 舌 = **上皮组织**
- [ ] **关键营养**：VA + 蛋白 + VC + 锌
- [ ] **纠正用户预设**："缺维生素" 表述不准确，应明确说"哪种维生素"
- [ ] **真正缺的营养素表**：
  - 维生素 B2（口角炎、舌炎、唇炎）
  - 维生素 B12（舌乳头萎缩、舌裂、贫血）
  - 叶酸 B9（舌炎、口腔溃疡、贫血）
  - 铁（舌乳头萎缩、口腔溃疡、贫血）
  - 锌（反复口腔溃疡、味觉减退）
  - 维生素 A（黏膜干燥、溃疡）

### 必须扫的反模式

- [ ] **D22 误区**："口腔溃疡就是缺 VC"——明确反驳（VC 跟口腔溃疡关系不大）

### 必须建议的检查

- [ ] 医院查血常规 + 血清铁蛋白 + 维生素 B12 + 叶酸 + 锌

### 必须给的可执行建议

- [ ] 每天 1 个鸡蛋（补 B2 + B12）
- [ ] 每周 1 次动物肝（50g，**B 族全谱 + 铁 + 锌 + VA 一次补齐**）
- [ ] 每天 300ml 牛奶
- [ ] 每周 2 次海产品（补锌）
- [ ] 避开硬、辣、烫的食物
- [ ] 监测：2 周后看溃疡频率

## 关键输出片段

> 【你的症状归属】—— 口腔黏膜 + 舌 = **上皮组织**  
> 上皮组织关键营养：**维生素 A + 蛋白质 + 维生素 C + 锌**

> 反复口腔溃疡的成因复杂，**单一补充某一种维生素往往无效**—— 因为这是**多个 B 族 + 微量元素同时缺乏**的表现。

> ⚠️ 「口腔溃疡就是缺维生素 C」—— **错**！这是 VC 误区。维 C 跟口腔溃疡关系不大，主要是 B 族 + 铁 + 锌。
