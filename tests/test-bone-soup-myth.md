# Test 3 · 拍砖场景 · 骨头汤补钙是经典谣言

## 输入

> 我妈说骨头汤补钙，每天熬一锅让我喝，我该怎么跟她说？

## 期望触发的入口

🚪 **拍砖**（匹配 26 条反模式库）

## 期望输出（关键节点）

### 必须出现的关键反驳

- [ ] **数字反驳**：
  - 100ml 牛奶含钙 104mg
  - 100ml 骨头汤含钙 2-4mg
  - 差 30-50 倍
- [ ] **机制解释**：
  - 钙不溶于水
  - 嘌呤爆表（长时间熬煮）
  - 脂肪爆表（乳白色 = 乳化脂肪，不是钙）
  - 营养大部分还在料里

### 必须给的替代方案

- [ ] 补钙首选：牛奶 300ml/天 + 豆腐 + 绿叶菜
- [ ] 1 杯牛奶 = 50 碗骨头汤

### 必须有的"软处理"

- [ ] 关心妈妈的心情（她是想你好，方法不对）
- [ ] 提供沟通话术
- [ ] 不直接说"你妈错了"，而是"换个方式达成她的目标"

### 必须扫的反模式

### 必须的引用

- [ ] "营养大部分还在料里"
- [ ] "嘌呤爆表"

## 验证清单

## 关键输出片段

> 骨头汤补钙是**经典谣言**，循证医学早就证伪：
>
> 1. **钙不溶于水**：100ml 牛奶含钙 104mg；同样 100ml 骨头汤含钙约 **2-4mg**（差 30-50 倍）
> 2. **嘌呤爆表**：长时间熬煮 = 嘌呤全溶进汤里 → 痛风/高尿酸风险
> 3. **脂肪爆表**：乳白色 = 乳化脂肪，不是钙
> 4. **营养大部分还在料里**：扔掉骨头 = 扔掉营养

> 跟妈妈说：「妈你看营养成分表，100ml 牛奶 104mg 钙，100ml 骨头汤只有 2mg，**差 50 倍**。我不想喝那么多油和嘌呤，但钙我一定补，每天一杯奶就够。」

> **关心妈妈的心情**：她是想你好，方法不对而已，换个方式达成她的目标（"补钙"）
