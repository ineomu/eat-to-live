# Test 6 · 比喻化解 · 胰岛素抵抗 = 山西煤老板送煤

## 输入

> 什么是胰岛素抵抗？为啥我得了糖尿病医生还要我运动？

## 期望触发的入口

🚪 **反查**（症状/机制 + 比喻化解）

## 期望输出（关键节点）

### 必须出现的核心比喻

- [ ] **山西煤老板送煤**：
  - 胰岛素 = 煤老板（送葡萄糖）
  - 葡萄糖 = 煤
  - 细胞 = 电热厂（接收葡萄糖）
  - 胰岛素受体 = 电热厂采购部
  - **胰岛素抵抗 = 采购部说"现在不是冬季，我不需要"**

### 必须解释清楚的核心机制

- [ ] **胰岛素抵抗不是病**—— 是人体在保护细胞不被过多能量撑死
- [ ] **细胞不需要这么多能量**—— 就像电热厂不需要这么多煤
- [ ] **运动的作用**：告诉细胞"现在冬天了，我需要煤" → 胰岛素受体变灵敏 → 同样的胰岛素能送进去更多葡萄糖

### 必须对比的"少吃"vs"运动"

- [ ] **少吃**：减少煤老板送煤，但采购部还是不收 → 血糖不降
- [ ] **运动**：让采购部重新需要煤 → 血糖下降 + 肌肉储备增加

### 必须包含的引用

- [ ] "细胞对氧的需求多了，细胞膜上的胰岛素受体的敏感性自然就会增强"
- [ ] "管住嘴的意思是不要吃太多碳水化合物，迈开腿的意思是增加运动，提高细胞对能量的需求"
- [ ] "胰岛素抵抗也许是好事"—— 因为这是人体在保护你不被过多能量撑死

### 必须给的运动建议

- [ ] 每周 5 天，每天 30-60 分钟有氧（快走/慢跑/游泳）
- [ ] 加 2 次力量训练（增肌 = 增加葡萄糖储备空间）
- [ ] 配合减负三法则

### 必须用的其他比喻（次要）

- [ ] 胰岛素受体是锁（钥匙开锁）

## 关键输出片段

> 【比喻：山西煤老板送煤】
>
> 胰岛素就是那个煤老板，葡萄糖就是煤。胰岛素受体就是电热厂的采购部。
>
> **胰岛素抵抗**就是采购部跟老板说："现在不是冬季，我不需要这么多煤"—— 也就是细胞不接受葡萄糖。
>
> 你得了 2 型糖尿病，**不是胰岛素不够**，而是细胞说"我不需要这么多"。

> 【为啥要运动】
>
> "管住嘴的意思是不要吃太多碳水化合物，迈开腿的意思是增加运动，提高细胞对能量的需求。"
>
> 运动 = 告诉细胞"现在冬天了，我需要煤" → 胰岛素受体变灵敏 → 同样的胰岛素能送进去更多葡萄糖 → 血糖下降。

> **所以运动**：
> - ✅ 增加细胞对能量的"需求"
> - ✅ 提高胰岛素受体敏感度
> - ✅ 增加肌肉储备葡萄糖
>
> **比"少吃"更根本**—— 少吃是减少煤老板送煤，但采购部还是不收；运动是让采购部重新需要煤。

> 胰岛素抵抗不是"胰岛素罢工"，是"细胞理性拒绝"。
