# Test 5 · 综合场景 · 爷爷糖尿病 5 年脚麻

## 输入

> 我爷爷 70 岁，糖尿病 5 年，最近脚有点麻。怎么办？

## 期望触发的入口

🚪 **综合**（体检 + 反查 + 拍砖 + 治疗边界判断）

## 期望输出（关键节点）

### 必须出现的关键判断

- [ ] **紧急评估**：脚麻 + 糖尿病 5 年 = **可能糖尿病周围神经病变**（必须就医）
- [ ] **就医建议**：神经电生理检查 + 下肢血管超声
- [ ] **触发"先调查再说话"**：必须问 8 个关键信息（不能直接开方）

### 必须走 NCPM 4 步法

- [ ] **营养评定**：列关键信息缺口
- [ ] **营养诊断**：4 大组织（神经 + 上皮 + 肌肉）
- [ ] **营养干预**：糖尿病专项 + 神经专项 + 老人专项
- [ ] **监测与评价**：完整时间表

### 必须给的糖尿病专项

- [ ] **减负三法则**：
  - 少碳水（让 β 细胞休息）
  - 给结构原料（鱼/蛋/瘦肉/奶 → 蛋白磷脂胆固醇）
  - 多运动

### 必须给的神经组织专项

- [ ] 每天 1 个鸡蛋 + 300ml 牛奶 + 100g 瘦肉/鱼
- [ ] 每周 1-2 次动物肝（补 B12 + 胆碱）
- [ ] 每周 2-3 次深海鱼（补 ω-3 + 维 D）
- [ ] 粗粮 1/2-2/3

### 必须给的老人专项

- [ ] 蛋白 1.2-1.5g/kg（比年轻人更需要）
- [ ] 钙 1000-1200mg/天
- [ ] 维 D 800-1000IU/天

### 必须扫的 4 大反模式

- [ ] **D6/D7** 「糖尿病人要清淡饮食」—— 错！缺蛋白 → 脚麻加剧
- [ ] **D24** 「少吃饭就能降糖」—— 错！减掉结构 → 神经损伤更快
- [ ] **D18** 「骨头汤补钙」—— 错
- [ ] **D22** 「糖尿病不能吃水果」—— 错（看 GL 不看 GI）

### 必须给的可执行

- [ ] "3 件小启动"：每天早上 1 蛋+1 奶+1 全麦面包、每周 1 次猪肝、每天 30 分钟散步
- [ ] 复查时间表：2 周 / 1 月 / 3 月 / 6 月

### 必须包含的引用

- [ ] "糖尿病周围神经病变是**长期高血糖 + 营养代谢紊乱**的双重结果"
- [ ] "糖尿病周围神经病变可逆吗？**早期可逆**，晚期难逆"

> 脚麻 + 糖尿病 5 年 = **可能糖尿病周围神经病变**（下肢 + 上肢都可能受累）
