# Test 2 · 40 岁男性跑者 · 运动量大但缺关键营养

## 输入

```
基础信息：男，40 岁，175cm，70kg，体脂率 16%，每月慢跑 80km 左右，静息心率 56 左右。

1. 你的工作—— 久坐为主
2. 现在的饮食—— 早晨沙拉全麦面包，鸡蛋，生菜紫甘蓝等沙拉为主，中饭或晚饭鸡肉洋葱土豆米饭等，或者有时候早晨吃馄饨啥。一天两到三顿饭。自己做的占 70% 以上，外卖或饭店 30% 左右
3. 运动—— 每月固定跑步 80km，日均步数 1 万左右
4. 睡眠—— 12 点左右，睡眠还可以，平均 6-7 个小时左右。
5. 情绪压力—— 还可以，偶有压力但不是太大。
6. 烟酒—— 不抽烟喝酒
7. 现有疾病 + 用药—— 甲状腺结节，其他未全面检查
```

## 期望触发的入口

🚪 **体检**（5 分钟自测 + NCPM 4 步法）

## 期望输出（关键节点）

### 必须出现的关键诊断

- [ ] **BMI = 22.9** + 体脂 16% + 静息心率 56 = **运动员体格**（不是普通人）
- [ ] **TDEE 计算**：BMR 1600 × 活动系数 1.7 ≈ 2700 kcal/天
- [ ] **训练日 vs 休息日分别设计**
- [ ] **主诉优先级**：甲状腺 > 主食 GI > ω-3 > 钙 > 睡眠

### 必须识别的问题

- [ ] **甲状腺结节**：海产品 = 0、奶 = 0 → 缺碘缺蛋白
- [ ] **主食结构问题**：土豆（GI 78）+ 白米饭（GI 88）= 高 GI 炸弹
- [ ] **ω-3 严重不足**：没看到深海鱼/坚果
- [ ] **钙不足**：奶 = 0
- [ ] **睡眠 6-7h 略少**：耐力训练者建议 7-9h

### 必须给出的数字

- [ ] 训练日 2700-2900 kcal / 休息日 2300 kcal
- [ ] 蛋白 1.4-1.6g/kg = 98-112g/天
- [ ] 主食：训练日粗粮 2/3 + 细粮 1/3 / 休息日粗粮 1/2 + 细粮 1/2
- [ ] **训练后 30 分钟黄金窗口**补给方案
- [ ] 一周食谱（5 训练日 + 2 休息日分别）

### 必须引用的反模式

- [ ] **D17** 甲状腺结节戒碘盐（反向科普：海边人也缺）
- [ ] **D11** 植物蛋白代替动物蛋白

### 必须用的比喻

- [ ] 河流上中下游（定位甲状腺/主食/睡眠问题）

### 必须包含的引用

- [ ] "判断食物营养价值，看能量 + 营养素，不是习惯"
- [ ] "训练后 30 分钟内补蛋白 + 碳水，恢复效果最好"

## 验证清单

- [ ] 没有把"减重"当目标（他不需要）
- [ ] 没有"少吃饭多跑步"的错误减肥建议
- [ ] 主食替换方案给了具体克数
- [ ] 海产品 3-4 次/周
- [ ] 奶每天 300ml
- [ ] 坚果每天 10-15g
- [ ] 训练后补给方案具体到"蛋白奶昔 + 香蕉 + 全麦面包"
- [ ] 复查时间点包含 3 个月甲状腺 B 超
- [ ] 区分了训练日和休息日食谱

## 关键输出片段

> TDEE = 1600 × 1.7 ≈ **2700 kcal/天（训练日）** / **2300 kcal/天（休息日）**

> 你的"土豆 + 米饭"组合：土豆 GI=78、白米饭 GI=88，**两个高 GI 同时上场**

> **每周需 2-3 次深海鱼（鲈鱼/三文鱼/鳕鱼）+ 每天 10g 核桃/杏仁**

> **训练后 30 分钟内**：1 根香蕉 + 1 杯蛋白奶昔 + 全麦面包 1-2 片。**不要再练后空腹！**
