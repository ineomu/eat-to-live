## 🎯 它能做什么

当你跟 AI 聊到任何"吃饭"相关的话题，**eat-to-live** 会自动启动。它有 4 大入口，其中**拍一张饭菜照片发过去就能用**是最常用的打开方式：

| 你说 | 入口 | AI 做什么 |
|---|---|---|
| **（直接发一张饭菜照片）**「帮我看看这顿」 | 🚪 **评饭** | 先念出看到的菜品让你确认，再 100 分公式 + 三足鼎立 + 35:65 比例，一句话给补法 |
| 「我今天吃了 X，行不行」「帮我打个分」 | 🚪 **评饭** | 100 分公式 + 三足鼎立 + 35:65 比例，一句话给补法 |
| 「我最近 Y 不舒服」「我得了 Z 病」 | 🚪 **反查** | 4 大组织 + 上中下游，定位缺什么 + 怎么补 |
| 「我家人说 W 食物好/不能吃」「网上说 X 能治 Y」 | 🚪 **拍砖** | 26 条反模式库，引用研究证据反驳 |
| 「我想系统看看我吃得对不对」 | 🚪 **体检** | 5 分钟自测 + NCPM 4 步法，给完整营养诊断 |

**覆盖场景**：看图点评 / 评饭打分 / 症状反查 / 谣言拍砖 / 系统体检 / 减肥塑形 / 三高饮食 / 甲状腺结节 / 胃肠疾病 / 失眠抑郁 / 老人孕妇孩子特殊人群 / 慢病康复。

## 🚀 30 秒上手

把 `SKILL.md` 加载到你的 AI 助手（WorkBuddy/Claude / CodeX / 其他支持 Skill 的 agent），然后——

### 方式一：直接拍一张饭的照片发过去（最常用）

> 吃饭前掏出手机拍一张，配一句"帮我看看这顿"，完事。

AI 会先念出它看到的菜品让你确认，再给 100 分评估 + 补法：

```
【我看到的是】
红烧肉、白米饭、炒西兰花、一份紫菜蛋花汤——有漏掉或看错的吗？
（分量按标准份估算：米饭按一碗≈150g，肉按一掌心≈50g，不对请纠正我）

【你这顿的画像】
• 五大类缺了：水果（油在红烧肉里，但质量一般）
• 35:65 比例：动物约 45% / 植物 55%（动物偏多）
• 脂肪质量：红烧肉是饱和脂肪大户
• 升糖风险：白米饭是精制碳水，建议换杂粮饭

【一句话补法】
饭后补一个橘子；明天这顿把白米饭换成杂粮饭，
红烧肉减半、加一块豆腐。
```

### 方式二：打字描述也行

> "我今天早餐只吃了一个煮鸡蛋，怎么办？"

AI 会自动进入**评饭模式**，给你 100 分评估 + 一句话补法：

```
【你这顿的画像】
• 五大类缺了：粮 / 蔬 / 果 / 油
• 35:65 比例：动物 100% / 植物 0%（严重偏）
• 早餐 100 分：20 分（不及格）
• 升糖风险：低（没主食也不会高）

【一句话补法】
明天早餐目标 60 分：
  1 个煮蛋（已有）
  + 1 片全麦面包（粮 10 分）
  + 200ml 牛奶（蛋白 +10）
  + 半根黄瓜（蔬 10）
  = 70 分
```

### 💡 让建议更准的小技巧

AI 给方案前会按临床流程问你一些基础信息：年龄、身高体重、平时的饮食、运动睡眠、有没有基础病和在吃什么药。嫌来回问答麻烦的话，**第一句话就一次性说清**，比如：

> *"我 58 岁女性，155cm/53kg，有轻度肺结节和胆结石，平时不怎么运动，帮我看看每天蛋白和膳食纤维该吃多少。"*

你说得越全，方案越贴身。（这些信息只出现在你和 AI 的对话里，本项目不收集、不上传任何个人数据。）

## 🧠 底层逻辑（不是死记硬背）

本 skill 的方法论来自**国内三甲医院临床营养科的循证实践沉淀**，融合**国际营养学共识**：

```
                    【顶层信念】
                  慢病是生活方式病
              细胞损伤速度 > 修复速度
          修复的唯一原料 = 食物中的 7 大营养素
                          │
        ┌─────────────────┼─────────────────┐
        │                 │                 │
   【哲学层】         【流程层】         【工具层】
   - 7 大营养素      - NCPM 4 步法     - 🚪 评饭
   - 4 大组织        评定→诊断         - 🚪 反查
   - 上中下游          →干预→评价      - 🚪 拍砖
   - 35:65 比例                         - 🚪 体检
   - 没有坏食物
     只有坏搭配
```

**5 大核心框架**（每天会用）：

| 框架 | 一句话 |
|---|---|
| **七大营养素** | 碳水/蛋白/脂类/维生素/矿物质/膳食纤维/水 |
| **上中下游** | 慢病治理的河流模型：治上游（生活方式）> 治中游（指标）> 治下游（并发症）|
| **NCPM 4 步法** | 营养诊疗的国际标准流程（Academy of Nutrition and Dietetics, 2003）|
| **结构型 vs 能量原料** | "结构型能变能量，能量变不成结构"—— 减肥别减错 |
| **35% 动物 + 65% 植物** | 膳食结构金比例（地中海饮食研究）|

### ❓ 常见疑问：书那么厚，skill 里没有全书内容，回复靠谱吗？

**靠谱，恰恰是因为没塞全书。** 这个 skill 的定位不是"书的压缩包"，而是给 AI 装上**临床思维框架 + 防坑纪律**——就像资深医生带徒弟，重点不是让徒弟背下图书馆，而是教会他：先问什么、按什么流程判断、哪些坑不能踩、什么时候必须转诊。

具体靠三层机制保证质量：

1. **AI 本身已具备营养学通识**，skill 提供的是判断框架（四大组织 / 上中下游 / NCPM 流程），让通识被正确地组织和使用
2. **可量化的硬指标全部锚定权威指南**（膳食指南、DASH 研究、WHO 标准），不依赖任何单一书籍的经验数据
3. **26 条反模式库 + 证据分级**，防止 AI 顺嘴复述流传甚广的饮食误区

同时它也诚实地知道自己不是医生：所有建议都是营养教育与生活方式参考，**不替代医生面诊**（详见免责声明）。

## 📊 测试案例（真实场景）

> 6 个真实场景（已匿名化），全部跑通。完整测试集在 `tests/`。

### 案例 1：30 岁女性，BMI 19.5，想"减肥"

```
【关键诊断】
BMI 19.5 正常偏瘦，"减肥"不是真目标——
真正的优先级是：焦虑 > 甲状腺结节 > 幽门螺杆菌 > 体重

【7 大营养素目标】
能量 1500-1600 | 蛋白 75-80g | 粗粮 1/2-2/3
动物蛋白占一半 | 海产品每周 2-3 次（治甲状腺）

【一周食谱】
7 天 × 三餐 + 加餐，每餐标 100 分得分
```

### 案例 2：40 岁男性跑者，月跑 80km

```
【关键诊断】
BMI 22.9 + 体脂 16% + 静息心率 56 = 运动员体格
真问题：甲状腺结节 + 主食 GI 太高 + ω-3 不足

【训练日 vs 休息日分别设计】
训练日 2700-2900 kcal，休息日 2300 kcal
蛋白 1.4-1.6g/kg = 98-112g
训练后 30 分钟黄金窗口补给
```

### 案例 3：拍砖——"骨头汤补钙"

```
【这条不靠谱】
100ml 牛奶含钙 104mg
100ml 骨头汤含钙 2-4mg
差 30-50 倍
而且嘌呤爆表 + 脂肪爆表
```

### 案例 4：反查——"反复口腔溃疡"

```
【症状归属】口腔黏膜 + 舌 = 上皮组织
【关键营养】VA + 蛋白 + VC + 锌
【真正缺的】B2 + B12 + 叶酸 + 铁 + 锌（多种 B 族同时缺）
【反模式】"口腔溃疡就是缺 VC"——错
```

### 案例 5：综合——"爷爷 70 岁，糖尿病 5 年，脚麻"

```
【紧急】脚麻+糖尿病 5 年 = 周围神经病变，必须就医
【4 大组织】神经组织 + 上皮组织 + 肌肉组织
【干预】减负三法则 + 神经营养 + 老人防肌少症
【4 大反模式】"糖尿病人要清淡"——错
```

### 案例 6：比喻化解——"什么是胰岛素抵抗？"

```
【比喻】山西煤老板送煤——
胰岛素 = 煤老板（送葡萄糖）
细胞 = 电热厂（接收葡萄糖）
胰岛素抵抗 = 采购部说"现在不是冬季，我不需要"
运动 = 告诉细胞"现在冬天了，我需要煤"
```

## 🛠 怎么用

### 方法 1：WorkBuddy 用户（推荐，1 条命令）

```bash
git clone https://github.com/ineomu/eat-to-live.git ~/.workbuddy/skills/eat-to-live
```

装完开个新会话，直接说「我今天吃了一碗牛肉面」或「帮我评一下这顿饭」，skill 自动触发。不想用了，删掉这个文件夹即可。

> 想用 `git pull` 随时更新到最新版？可以把仓库克隆到别处（如 `~/skills/eat-to-live`），再软链接到 skills 目录：`ln -s ~/skills/eat-to-live ~/.workbuddy/skills/eat-to-live`。普通用户直接 clone 进 skills 目录就够了，无需这一步。

### 方法 2：其他支持 Skill 的平台

Kimi Agent、MiniMax Agent、IMA Copilot、Claude Projects、Cursor、Continue.dev 等——直接上传/导入整个 `eat-to-live/` 文件夹。

### 方法 3：直接用 Claude

把 `SKILL.md` 的内容复制到 Claude 的**项目知识（Project Knowledge）**或**自定义指令（Custom Instructions）**里，然后开聊。

### 方法 4：作为 Prompt 模板

`SKILL.md` 本身就是一份完整的 prompt 模板，你可以裁剪其中的"工作流"段用到任何 agent 里。

### 方法 5：用在 GPT / 其他 AI

把 `SKILL.md` 整段复制到 system prompt。触发场景识别靠 description 字段的关键词。
